# Weibull regression for seismic inter-event times at the unstable Åknes rock slope

This repository contains the code used to model inter-event waiting times in seismic activity at the Åknes rock slide (https://www.norsar.no/projects/monitoring-of-aknes-rockslide/).

## Scripts

PDP.py - Partial dependence and interpretability analysis

Predict_model.py - Rolling prediction and model evaluation

Weib-models.py - Baseline survival models

NN_models_(-2021).py - Neural network feature learning

NN_model.py - Extended neural network model with additional formatted covariates

quicktest.py - Test example for a small data set.


## Data availability 
The original dataset cannot be distributed publicly.
Users can run the workflow using synthetic or example data included in the repository.
